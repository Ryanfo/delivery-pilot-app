# Release proposal

> Provenance (ticket, revision, accepted candidate SHA) is added by the coordinator.

## Release notes
Adds a "Starred only" filter to the task list. A new checkbox next to the existing status
filter lets you show only the tasks you've starred. It combines with the status filter (for
example "In progress" + "Starred only" shows only starred, in-progress tasks), the task count
line and the empty-state message update to reflect the combined filter, and unstarring a task
while the filter is on removes it from the list immediately. The checkbox is unticked by
default, is not remembered between visits, and starring itself is unchanged.

## Smoke checks
1. Install and start the app: `npm ci`, then `npm run dev` (or `npm run preview` after
   `npm run build`), and open it in a browser.
2. Confirm a "Starred only" checkbox with a visible label appears next to the "Status" filter
   and is unticked on load (AC1).
3. Star two or more tasks with different statuses using their existing "Star"/"Unstar"
   control.
4. Tick "Starred only" and confirm only the starred tasks are listed, and the "Showing X of Y
   tasks" line's X matches the starred count while Y stays at the total (AC2, AC6).
5. With "Starred only" still ticked, change the "Status" filter (e.g. to "In progress") and
   confirm the list narrows to tasks that are both starred and match that status (AC3).
6. With "Starred only" ticked, click "Unstar" on one of the visible tasks and confirm it
   disappears from the list immediately, with no other interaction (AC4).
7. Keep ticking "Starred only" until no starred task matches the current status filter and
   confirm the "No tasks match the current filter." message is shown (AC5).
8. Click the "Starred only" label/checkbox area with a mouse to untick it, then confirm the
   full list returns.
9. Using only the keyboard, Tab to the "Starred only" checkbox and press Space; confirm it
   toggles on and off and the list updates accordingly (AC7).
10. Reload the page and confirm "Starred only" resets to unticked (by design — not persisted),
    while previously starred tasks remain starred.
