# Implementation plan: Add a "HELLO WORLD" welcome block to the task list page

> Provenance is added by the coordinator. Implements the approved specification revision named in the provenance.

## Approach
Add a static `<section aria-label="Welcome">HELLO WORLD</section>` element in `src/App.tsx`,
placed directly between the `<h1>Task list</h1>` heading and the `<div className="controls">`
status filter block. A `<section>` with a non-empty `aria-label` exposes the implicit ARIA
role `region` with that label as its accessible name, satisfying AC2 without any new CSS,
props or dependencies. The visible text node is exactly `HELLO WORLD`, satisfying AC1 and AC3.
No existing state, props, domain logic or storage is touched, so filtering, starring and the
task count are unaffected (AC5).

## Affected files
| Path | Change |
|---|---|
| `src/App.tsx` | modify: insert `<section aria-label="Welcome">HELLO WORLD</section>` between the `<h1>` and `<div className="controls">` |
| `src/App.test.tsx` | modify: add a unit test asserting the block renders with the exact text "HELLO WORLD" |
| `e2e/app.spec.ts` | modify: add an assertion that the block is visible on load |

## Interfaces and data
No exported functions, types, storage formats or schemas are added or changed. The `App`
component's props (`tasks`, `store`) and return shape are unchanged; this is a static JSX
addition only.

## Implementation steps
1. In `src/App.tsx`, inside the `<main>` element, insert
   `<section aria-label="Welcome">HELLO WORLD</section>` immediately after `<h1>Task list</h1>`
   and immediately before `<div className="controls">`.
2. In `src/App.test.tsx`, add a test case in the `describe("App", ...)` block: render `<App store={memory()} />` and assert
   `screen.getByRole("region", { name: "Welcome" })` has text content `"HELLO WORLD"` (e.g. via
   `toHaveTextContent("HELLO WORLD")`), confirming the exact text renders.
3. In `e2e/app.spec.ts`, add an assertion in the existing test (or a new `test(...)` block if
   that reads more clearly) that
   `page.getByRole("region", { name: "Welcome" })` is visible and has text `"HELLO WORLD"`,
   confirming the block is visible when the app loads.
4. Run `npm run lint`, `npm run typecheck`, `npm run test:unit`, `npm run build`, and
   `npm run test:e2e` locally to confirm no regressions and that all configured checks pass.
