# Release proposal

> Provenance (ticket, revision, accepted candidate SHA) is added by the coordinator.

## Release notes
The task list page now shows a "HELLO WORLD" welcome block directly below the "Task list"
heading. This is a static, read-only confirmation banner — it does not change how tasks are
listed, filtered, starred or counted. The block is implemented as a semantic `<section>` with
an accessible name so screen readers announce it as a named landmark.

## Smoke checks
1. Start the app locally (`npm install` then `npm run dev`, or the project's usual local-pilot
   start command) and open it in a browser.
2. Confirm the "Task list" heading is visible at the top of the page.
3. Confirm a block with the exact text "HELLO WORLD" (in capitals) appears directly below the
   heading and above the status filter control.
4. Using a screen reader or the browser's accessibility inspector, confirm the block exposes
   an accessible landmark (role `region`) rather than being plain unlabelled text.
5. Change the status filter dropdown and confirm the task list still filters correctly and the
   "Showing X of Y tasks · Z starred" count still updates.
6. Star a task, reload the page, and confirm the star persists as before.
7. Confirm no other visual or behavioural change is present elsewhere on the page.
